THE SCATHING CHARTER - offline edition
======================================

Where it goes
  Extract the ZIP into C:\Games so that you get C:\Games\AshGame
  (inside it: "Play The Scathing Charter.cmd", "game", "launcher", this file).

How to play
  1. Double-click  "Play The Scathing Charter.cmd".
  2. A small black window appears (the game's engine) and Google Chrome opens the game
     in its own window - even though Firefox is your default browser.
  3. Play! When you close the game window, the black window closes by itself.

  Optional: double-click "Make desktop shortcut.cmd" once to get an
  "The Scathing Charter" icon on your desktop.

  Updating from the old "Ashfall Ledger" version: extract over the old folder and choose
  "Replace". Your saves are kept. The old "Play Ashfall Ledger.cmd" can be deleted.

  No internet is needed. You need Node.js (already installed) and Google Chrome.

Your saves
  The game saves automatically after every action. Saves live in the
  "chrome-profile" folder inside C:\Games\AshGame, separate from your normal Chrome.
  - Do not delete "chrome-profile" unless you want to start over.
  - For a backup: in the game, menu (the three lines at the top right) > Export save file.
  - Moving the whole AshGame folder elsewhere keeps your saves.

If something goes wrong
  * "Windows protected your PC": click "More info" > "Run anyway" (it is a plain text script;
    right-click > Edit to read it).
  * "Node.js was not found": install Node.js LTS from https://nodejs.org, restart, try again.
  * Chrome does not open: the black window prints an address (http://127.0.0.1:51735/).
    Open Chrome yourself and type it in. Keep the black window open while you play.
  * The black window says the game is "already running": a game window is open somewhere,
    possibly behind other windows. Use that one, or close it and start again.
  * A blank page: press Ctrl+F5 in the game window.
