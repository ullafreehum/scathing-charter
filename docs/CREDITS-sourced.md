# Sourced art: credits and licences

All files below come from **The Battle for Wesnoth** (open-source game), repository
https://github.com/wesnoth/wesnoth at commit `08a640021eef0ba80798e7af222a9b5c1070557a`,
fetched 2026-10-17. Painted story art, not icon art.

**Licence: GNU GPL v2 or later** (Wesnoth's default for all its art). The Scathing Charter repo is
GPL-3.0, so these can ship in the game: keep this credit file, name Wesnoth and its artists in the
in-game credits, and keep any edited versions under the GPL too.

Note: GPL is not on our usual CC0/CC BY/CC BY-SA/OFL list. It is compatible here only because the
game itself is GPL-3.0. If the game licence ever changes, these files must be replaced.

Why Wesnoth: from this container every museum API, Openverse, Wikimedia, archive.org, NASA, itch.io
and OpenGameArt are blocked. Only public GitHub repos are reachable.
